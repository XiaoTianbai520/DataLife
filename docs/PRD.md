## 一、产品定位与目标

### 1.1 产品定位
打造一个常驻个人电脑桌面、完全运行在本地的**“数字生命”陪伴型聊天机器人**。

与“你问我答、被动待命”的效率型 AI 助手不同，本产品定位于**拟人化桌面伴侣**：它能感知你当下所处的电脑环境与使用场景，拥有持续流动的内心情绪和自主表达意愿——不是随时等待指令的工具，而是一个会悄悄观察、独立思考、想说才说的数字伙伴。

### 1.2 产品目标

| 目标维度 | 核心目标描述 | 达成标准（衡量口径） |
| :--- | :--- | :--- |
| **陪伴真实感（核心）** | 让用户感受到角色拥有独立的意识流与情绪，而不是机械的定时播报或一问一答 | 角色能够根据观察到的画面与体感温度自主决定“保持沉默”或“主动搭话”，且多次观察间的情绪与思绪前后连贯 |
| **低打扰与高语境贴合** | 做到“该安静时安静，开口时言之有物”，不打断用户深度工作 | 主人未说话时不刷屏打扰；主人主动发起聊天时，回应能自然结合眼前场景与过往记忆 |
| **本地隐私安全** | 保障用户屏幕内容与个人对话数据的绝对私密性 | 核心感知、思考与记忆能力全部运行在本地；屏幕画面仅作瞬时理解，不留存任何历史截图 |
| **轻量运行与可持续成长** | 在普通个人电脑上可长期后台常驻，且角色感官能力可随版本逐步丰富 | 后台常驻不明显影响日常办公、编程或娱乐体验；后续扩展新感官不影响既有交互体验 |

### 1.3 核心场景
* **静默陪伴**：用户专注学习、编码或看视频时，角色在后台观察并更新自己的内心独白，自主选择不打扰。
* **自然破冰**：当电脑持续发烫、用户长时间停留在同一画面或切换娱乐活动时，角色基于当下情绪自主决定是否开口关心或吐槽。
* **随时对话**：用户主动找它聊天时，角色优先响应，并自然结合“此刻看到的桌面内容”与“之前聊过的事”展开对话。

## 二、功能需求清单

| 功能模块 | 子功能 | 功能描述 | 优先级 |
| :--- | :--- | :--- | :---: |
| **感官系统** | 电脑体感温度感知 | 感知电脑当前的冷热状态（模拟皮肤触觉），让角色产生“好热/舒适”等主观体感 | P0 |
| | 桌面视觉感知 | 周期性观察主人当前的电脑屏幕内容（模拟视觉），理解主人正在进行的活动 | P0 |
| | 感官自由扩展 | 支持后续无痛新增更多感官能力（如听觉感知播放音乐、活跃度感知发呆时长等） | P1 |
| **自主交互与对话** | 主人主动对话 | 主人随时可主动发起对话，角色优先响应并结合当下环境进行交流 | P0 |
| | 周期性自主观察 | 按设定时间间隔自动唤醒一次，结合最新环境感知进行独立思考 | P0 |
| | 自主发言与沉默权 | 角色每次思考都会产生内心独白，仅当它自己决定开口时，才会向主人展示对话内容 | P0 |
| | 持续内心情绪流 | 上一轮未说出口的内心想法会延续至下一轮观察，形成连贯的情绪演变 | P0 |
| | 走神/轻状态反馈 | 当主人主动搭话但角色未直接开口时，呈现柔和的动作状态提示（如“悄悄看了一眼屏幕”），维持沉浸感 | P1 |
| **记忆系统** | 短期对话连贯 | 保持最近几轮对话的即时记忆，确保日常交流中能听懂代词指代与连续追问 | P0 |
| | 长期记忆沉淀与回忆 | 自动沉淀重要事实、主人偏好与过往观察到的事件，在未来合适时机自然回忆并提起 | P0 |
| | 视觉瞬时遗忘 | 观察过的桌面画面仅用于当下理解，不保留历史画面，仅将值得记住的印象转化为文字记忆 | P0 |
| **桌面呈现与配置** | 聊天窗口与桌面气泡 | 展示角色对外说出的话，支持主人文本输入与历史对话浏览 | P0 |
| | 角色人设配置 | 支持自定义角色的性格、称呼与表达风格 | P0 |
| | 观察频率与隐私开关 | 支持调整定时观察频率，支持一键暂停视觉感知或进入免打扰静音模式 | P1 |

## 三、MVP 范围与功能边界

为控制单人开发复杂度、避免核心体验失焦，明确界定本产品的 MVP 范围与边界如下：

### 3.1 本期包含范围（In-Scope，MVP 1.0）
* 完成**全部 P0 级核心功能**，跑通“环境感知（温度 + 桌面视觉） -> 周期性自主思考 -> 自主决定说话或沉默 -> 短期与长期记忆”的完整陪伴闭环。
* 提供基础、轻量的桌面对话/气泡交互界面与角色人设配置入口。
* 仅支持单机本地运行、单一专属角色与主人的一对一陪伴交互。

### 3.2 明确不做范围（Out-of-Scope）
以下能力明确排除在产品边界之外（或不在中短期规划内）：

| 排除项 | 边界说明与原因 |
| :--- | :--- |
| **电脑操控与效率执行（GUI Agent）** | **不替用户操作电脑**（不点击鼠标、不输入键盘、不自动修代码、不管理文件、不执行系统命令）。本产品聚焦情绪陪伴，不做自动化办公工具 |
| **云端账号体系与多端同步** | **不提供注册登录与云端数据同步**。所有记忆与对话完全保存在本地，优先保证隐私安全与单人维护成本 |
| **屏幕历史留痕与监控回溯** | **不保存历史截图相册或屏幕录屏**。视觉感知严格遵循“阅后即焚”，杜绝隐私泄露隐患 |
| **复杂 3D / Live2D 骨骼动画系统** | **MVP 阶段不开发重度美术渲染与复杂肢体动作编辑器**。先用极简桌面气泡/静态立绘跑通“灵魂（大脑与记忆）”，避免陷入前端美术泥潭 |
| **多角色社交与群聊生态** | **不支持多机器人互相聊天或接入公共社交群聊**。聚焦桌面上唯一数字生命的深度记忆与专属羁绊 |
| **强制定时播报/闹钟提醒系统** | **不做日程管理或番茄钟工具**。角色主动说话必须源于自身的感受与情绪，而非替代系统日历发通知 |

### 3.3 版本演进规划
* **MVP 1.0（灵魂闭环版）**：仅覆盖全部 **P0** 功能，验证核心陪伴体验与本地运行稳定性。
* **V1.1（体验与扩展版）**：覆盖 **P1** 功能，补齐隐私静音开关、走神状态反馈，并接入至少 1 个新增扩展感官（如听觉/键鼠活跃度）。
* **V1.2（沉浸交互版）**：探索 **P2** 功能，丰富桌面视觉呈现。
